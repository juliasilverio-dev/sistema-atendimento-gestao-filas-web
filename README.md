# Sistema de Atendimento e Gestão de Filas

Projeto acadêmico de um sistema web para geração de senhas não sequenciais e gerenciamento de filas de atendimento para consultas, exames e agendamentos. O atendimento deve priorizar a categoria preferencial e respeitar a ordem de geração das senhas dentro de cada categoria.

A proposta inclui a simulação de um totem para emissão de senhas, a visualização das filas e uma interface para realizar os atendimentos.
